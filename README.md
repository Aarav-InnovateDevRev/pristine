# Pristine - AI File Guardian 🛡️

**A smart, safe, and lightweight tool to keep your PC clean.**

Pristine automatically monitors your Downloads and Screenshots folders, shows a clean popup when new files arrive, and intelligently suggests old/unused files for deletion.

### ✨ Key Features

- Real-time notification popup on new downloads/screenshots
- Quick actions: **Important • Normal • Skip**
- Smart rule-based AI for cleaning suggestions
- Protected Keywords system (protect games, setups, projects, etc.)
- Multi-select Review Queue
- All deletions go to **Recycle Bin** first (never permanent)
- Clean modern tabbed interface
- Runs smoothly in background

### How to Use

1. Download `Pristine.exe`
2. Run it once (accept the safety notice)
3. Add important keywords (setup, game, project, etc.)
4. Let it help you maintain a clean PC!

### Safety First
- No files are deleted without your approval
- Everything goes to Recycle Bin
- Works completely offline
